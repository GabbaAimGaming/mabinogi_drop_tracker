カレンとドロップ記録 v0.12

■ 起動
ZIPを全部展開して、KarenDrop.exeをダブルクリックしてください。
Pythonのインストールは不要です。黒いCMD画面は出ません。
EXEだけを取り出さず、_internal、assets、referencesなども同じフォルダーに置いてください。
Windows 64ビット向けです。初回のダウンロード時にWindowsの確認が出る場合があります。

■ 以前のデータを引き継ぐ
前のツールを終了してバックアップしてください。
新しいKarenDropフォルダーへ、以前のdataフォルダーとexclusions.jsonをコピーします。
名前・周回・学習・除外設定を引き継ぎます。.venvはコピー不要です。

■ 使い方
ダンジョン・難易度・ネアルを選び「入場：新しい周回」。
クリア報酬だけを画面中央にALT表示して待ちます。
「5秒後に報酬を読取」は、押してからゲームへ戻ってALT表示してください。
読取後は履歴で品名と扱いを確認し、周回を確定します。
道中や他人のドロップとの区別はできません。
日本語OCRにはWindowsの日本語OCR機能が必要です。

【v0.12の変更】
大きなタイトル欄をなくし、カレンと撮影ボタンを監視操作の下に埋め込みました。
初期ウィンドウは1020×760。選択しているタブが高く表示されます。
「CSV：プレイヤー別」「CSV：全体集計」を追加しました。

【CSV集計】
本ツールが出力した、プレイヤー名付きのUTF-8 CSVを読み込めます。
プレイヤー別では名前を選択し、全体集計では読み込んだ全員のデータをまとめます。
ダンジョン・難易度・ネアル別に分け、「全エリア」または条件を選んで表示できます。
全体の率は出現周回合計÷集計済み周回合計。未確認周回は分母から除外します。
自分の周回履歴は自動では混ぜません。含めたい場合は自分のCSVも読み込んでください。

同じ名前・同じ条件のCSVは、後で読み込む内容に置換します。足し算しません。
内容が変わるときは確認画面で周回数の変化を表示します。古いCSVを読むと古い内容に戻ります。
同時に選択した複数ファイルで同じ名前・条件の内容が異なる場合は読込を中止します。
CSVに含まれていない条件は以前の内容を保持します。不要ならプレイヤー単位で削除してください。
区間別CSVの足し算はできません。1人・1条件につき最新の累積CSVを使用してください。
同名の別人は区別できないため、プレイヤー名にサーバー名等を加えて区別してください。
比較する人同士で除外対象と品名表記を揃えてください。

読込済みCSVはdata/csv_imports.jsonへ保存し、再起動後も表示します。
「この人の読込データを削除」はCSV比較用データだけを削除します。元CSVと周回履歴は残ります。
更新時はdata全体とexclusions.jsonを新しいEXEの隣にコピーすると引き継げます。


v0.12：読取完了音と設定欄を削除。CSVタブでダンジョン単位の合算、およびアルビ＋夢幻ラビ誘惑の合算を選択できます。アルビは全難易度、夢幻ラビは誘惑のみ、ネアル条件は両方を含みます。未確認周回は分母に含めません。各条件の選択肢はCSV読込後に増えます。


v0.12：OCRは元のカラー画像を白黒化せず、Lanczos補間で3倍へ拡大して読みます。確認画像もカラー・滑らかな拡大が標準です。保存済み画像・名前学習・統計は変更しません。拡大で元にない文字情報を復元する機能ではなく、実ゲームでの精度改善は要検証です。既存の誤認識名は自動修正しません。


v0.12：読取完了音を復活。オリジナルの短い2音チャイムを同梱しています。自動読取・5秒後読取で結果の保存が完了した際に鳴り、画像テストや読取失敗時には鳴りません。ON/OFFはdata/notification.jsonに保存します。試聴はOFFでも再生できます。音量はWindowsのアプリ別音量で調整できます。


v0.12：発光する箱に重なる品名行の補助検出を追加。白・緑に加えて水色の文字を対象にし、純青の名前や孤立したHUD断片を避けます。元PNGの11行を検出する回帰テストを追加しました。OCR正解率を保証するものではありません。隙間のない「炎の糸金貨」は1行のままのため、履歴で確認してください。

難易度候補に「音楽」を追加。「マス／音楽」で記録できます。
