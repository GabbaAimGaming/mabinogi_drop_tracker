# カレン版の起動

Python不要の配布ZIPは「mabinogi-drop-tracker-karen-v0.12-windows.zip」です。
展開してKarenDrop.exeを起動します。詳しい引継ぎはREADME_EXE.txtを参照してください。
このソース版はPython 3.12でstart.batを使います。

ボタンの右側から「5秒後に報酬を読取」を指す配置です。

# マビノギ・ドロップ記録 v0.12

Windows用Python 3.12（64ビット、tcl/tk機能付き）が必要です。
初めて使う人は「mabinogi-drop-tracker-v0.12.zip」を書込み可能なフォルダーへ展開し、start.batを起動します。
初回は依存ライブラリを取得するためネット接続が必要です。Codexは不要です。
友人に渡す場合は配布ZIPを渡してください。自分の.venv、.venv-portable、dataを入れないでください。

## 使い方

1. プレイヤー名を入力し、名前を保存します。名義は過去分を含むこのデータ一式に適用します。
2. ダンジョン・難易度・ネアル使用を選び、「入場：新しい周回」。アルビHDはネアル使用が初期値です。
3. クリア後、自分の報酬の名前を画面中央にALTで表示します。同じ品名を3回連続で確認すると保存し、監視を止めます。
4. 読取完了の表示を確認したらALTを離せます。履歴で品名・集計対象を確認し、周回を確定してください。
5. CSV出力でプレイヤー名付きの統計を保存できます。

道中の品名と宝箱の報酬は区別しません。道中でも名前を表示する場合は監視を停止してください。
他人の報酬の所有者は判別しません。自分の品だけが見える状態で使います。
ALTキー自体は検出せず、画面上の文字を認識します。箱の角度や登録は不要です。
読取範囲は画面横22～80%、縦12～82%です。ゲームは手前に表示してください。
「5秒後に報酬を読取」も利用できます。1枚だけの読取は全行確認待ちになります。

横並びの品名は、背景板の切れ目が見えるときに分割します。背景が暗く切れ目がない場合や文字が重なる場合は分離できないことがあります。
確認画像は白黒表示と元画像を切り替えられます。小さな文字の失われた線は復元できません。
画面倍率・描画設定が異なる環境の認識対応は引き続き検証が必要です。

## 起動に困ったとき

診断.batは記録を変えずに、画面機能・参照画像・除外設定・書込み・画像ライブラリ・日本語OCRを確認します。
結果は環境診断.txtに保存します。標準Pythonがない場合は診断自体を起動できないので、まずPython 3.12を準備してください。
OCRだけに問題がある場合は起動を続けられます。学習済み画像の照合と手動登録は使えますが、未知名のOCRはできません。
OCR診断は無地PNGの読込みまで確認します。日本語の認識精度を測る検査ではありません。

start.batはCodexのキャッシュを参照しません。このPCで実行できる既存環境があれば使い、なければ.venv-portableを作ります。
既にある.venv-portableが破損している場合は勝手に削除・上書きせず停止します。診断結果を添えて相談してください。
ソフトとdataへ書き込める場所を使用してください。Program Filesなど読取専用の場所は適しません。

## 記録と統計

データ・学習内容はdata、除外ルールはexclusions.jsonに保存します。更新時に置き換えないでください。
確認済み周回に品名が含まれた割合を計算します。数量や宝箱1個あたりの確率ではありません。
未取得・確認待ちは分母に含めません。CSVの出現率は0～1で保存します。
履歴で周回を削除できます。学習と従来のバックアップ・証拠画像は保持します。
過去に結合して読み取った行は、新版にしても自動分割されません。

71件の自動テストとTk画面の初期化を確認済み。別PCのクリーンインストール、実ゲームでの撮影、漢字OCR精度は未検証です。

小さい画面では全体を縦横スクロールできます。通常サイズではバーを隠します。


【v0.12の変更】
大きなタイトル欄をなくし、カレンと撮影ボタンを監視操作の下に埋め込みました。
初期ウィンドウは1020×760。選択しているタブが高く表示されます。
「CSV：プレイヤー別」「CSV：全体集計」を追加しました。

【CSV集計】
本ツールが出力した、プレイヤー名付きのUTF-8 CSVを読み込めます。
プレイヤー別では名前を選択し、全体集計では読み込んだ全員のデータをまとめます。
ダンジョン・難易度・ネアル別に分け、「全エリア」または条件を選んで表示できます。
全体の率は出現周回合計÷集計済み周回合計。未確認周回は分母から除外します。
自分の周回履歴は自動では混ぜません。含めたい場合は自分のCSVも読み込んでください。

同じ名前・同じ条件のCSVは、後で読み込む内容に置換します。足し算しません。
内容が変わるときは確認画面で周回数の変化を表示します。古いCSVを読むと古い内容に戻ります。
同時に選択した複数ファイルで同じ名前・条件の内容が異なる場合は読込を中止します。
CSVに含まれていない条件は以前の内容を保持します。不要ならプレイヤー単位で削除してください。
区間別CSVの足し算はできません。1人・1条件につき最新の累積CSVを使用してください。
同名の別人は区別できないため、プレイヤー名にサーバー名等を加えて区別してください。
比較する人同士で除外対象と品名表記を揃えてください。

読込済みCSVはdata/csv_imports.jsonへ保存し、再起動後も表示します。
「この人の読込データを削除」はCSV比較用データだけを削除します。元CSVと周回履歴は残ります。
更新時はdata全体とexclusions.jsonを新しいEXEの隣にコピーすると引き継げます。


v0.12：読取完了音と設定欄を削除。CSVタブでダンジョン単位の合算、およびアルビ＋夢幻ラビ誘惑の合算を選択できます。アルビは全難易度、夢幻ラビは誘惑のみ、ネアル条件は両方を含みます。未確認周回は分母に含めません。各条件の選択肢はCSV読込後に増えます。


v0.12：OCRは元のカラー画像を白黒化せず、Lanczos補間で3倍へ拡大して読みます。確認画像もカラー・滑らかな拡大が標準です。保存済み画像・名前学習・統計は変更しません。拡大で元にない文字情報を復元する機能ではなく、実ゲームでの精度改善は要検証です。既存の誤認識名は自動修正しません。


v0.12：読取完了音を復活。オリジナルの短い2音チャイムを同梱しています。自動読取・5秒後読取で結果の保存が完了した際に鳴り、画像テストや読取失敗時には鳴りません。ON/OFFはdata/notification.jsonに保存します。試聴はOFFでも再生できます。音量はWindowsのアプリ別音量で調整できます。


v0.12：発光する箱に重なる品名行の補助検出を追加。白・緑に加えて水色の文字を対象にし、純青の名前や孤立したHUD断片を避けます。元PNGの11行を検出する回帰テストを追加しました。OCR正解率を保証するものではありません。隙間のない「炎の糸金貨」は1行のままのため、履歴で確認してください。

難易度候補に「音楽」を追加。「マス／音楽」で記録できます。
