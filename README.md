# KarenDrop v1.1.7

マビノギの画面に表示されたドロップ品名を読み取り、周回ごとの記録・確認・集計を行うWindowsツールです。

## ダウンロード

[公開リリース](https://github.com/GabbaAimGaming/mabinogi_drop_tracker/releases)のAssetsから `KarenDrop-v1.1.7-windows.zip` を取得し、すべて展開して `KarenDrop.exe` を起動してください。
Pythonの導入は不要です。Source code ZIPは開発者向けです。

操作は [README_EXE.txt](README_EXE.txt)、更新・復旧は [更新方法.txt](更新方法.txt)、制限と回避方法は [現在の問題点と対処方法.txt](現在の問題点と対処方法.txt) を参照してください。
OCR結果は確認してから確定してください。人形カバンなどが先に拾った品は画像から取得できません。

## 開発

構成・テスト・EXE作成は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。
記録、学習データ、提供者の画面サンプル、認証情報はリポジトリに含めません。
依存ソフト・モデル・画像等の権利情報は `licenses/` を確認してください。リポジトリのMITライセンスは第三者素材の権利を変更しません。

## v1.1.7の変更

KarenDrop v1.1.7

・配布EXEのHTTPS通信で必要なファイルの同梱漏れを修正しました。「更新を確認」「旧版一覧を取得」で No such file or directory が発生する問題を再現し、修正後の通信成功を確認しています。
・ビルド時にSSL実装が必要とする信頼設定ファイルを同梱し、欠けた状態ではビルドを停止します。配布EXEの自己診断にもHTTPS初期化の確認を追加しました。証明書の検証・信頼設定は維持します。
・辞書・モデル・周回記録の形式は変更していません。

v1.1.6で更新機能が使えない場合：
このReleaseに添付した「KarenDrop-v1.1.6-更新通信の復旧.zip」をダウンロードしてください。KarenDropを終了し、ZIP内の_internalフォルダーをKarenDrop.exeと同じ場所へ追加してから起動し、「更新を確認」を押してください。既存の_internalフォルダーは削除しないでください。
復旧ZIPは必要なファイル1個だけを追加し、data・辞書・設定には触れません。

Illegal byte sequence については、報告された実機での再確認が必要です。同じ通信準備の処理に関係する可能性がありますが、このエラー自体の再現には至っていません。

## v1.1.6の変更

KarenDrop v1.1.6

・アイテム管理の現在の除外設定を、過去の確定済み周回の統計・CSV出力にも反映するよう修正しました。スピリットジェムなどが過去に「集計」で保存されていても、現在「除外」なら集計から外れます。
・元の周回記録・確認済み周回数は変更しません。「集計」に戻しただけで、過去の除外行や未確認行を自動加算することもありません。
・一般向けZIPから配布者向け更新手順と旧方式の初期登録JSONを除外し、設定画面の配布者用JSON作成機能を整理しました。GitHubからの自動更新・旧版への切り替えは引き続き利用できます。
・旧版一覧の再取得に失敗した後も、プルダウンを開き直して再試行できるよう修正しました。
・未使用の読み込みを整理し、除外設定の反映範囲がわかるよう案内とコメントを修正しました。

すでに保存・共有したCSVは自動では書き換わりません。更新後に出力し直してください。CSV比較タブは読み込んだCSVを表示するため、再出力したCSVを読み直してください。

## v1.1.5の変更

KarenDrop v1.1.5

・旧版プルダウンを初めて開くと、GitHub Releasesの旧版一覧を自動取得するようにしました。起動時の更新確認中は、その完了後に取得します。
・紫・ピンク寄りの品名を、背景板と字形を確認する専用経路で検出します。紫の発光・ゲージ・アイコンをそのまま品名にしません。
・紫文字を品名照合・読取結果の再利用・横に並んだ品名の分割・ALT表示判定・表示倍率の推定へ対応させました。

日本語の見本を紫に着色した模擬画像（通常・2倍・3倍）と既存サンプルで検証しています。今回報告された実際の紫文字ALT画像は未検証です。発光や文字の重なり等で読み落とす場合は、v1.1.4で追加した手動撮影・周回内修正を使用してください。
大型モデル・辞書・提出画像は追加していません。

## v1.1.4の変更

KarenDrop v1.1.4

・手動操作を「3秒後に撮影」→「画像で確認・読取」→周回へ反映、に変更。外部画像の試し読みボタンを置き換えました。
・履歴で選んだ周回の画像を表示し、読取後は確認してから、その周回だけを確認待ちとして更新します。
・「この周回だけ修正・分割」を追加。結合した品名は1行1品で入力して分割でき、空欄で不要な行を除けます。共通学習は変更しません。
・手動の元画像は撮り直しで前の1枚を整理し、周回確定後に削除。自動・通常手動のサンプルも確定後に整理します。確認待ち・明示した提出用撮影・学習画像は保持します。
・宝箱の記憶期限内に始めたALT確認が、期限切れで探索に戻る問題を修正。ネアル確認中の重い探索も省略します。
・設定にGitHub Releasesの旧版プルダウンと「この版に戻す」を追加。履歴・設定・学習データを保持して戻せます。

青い発光や品名で隠れた宝箱の初回検知、重なった品名、ジェム等のアイコンの誤検出、一部装備名の誤読は残ります。画像の再読取で必ず直るものではありません。
「3→触媒」等の別アイテムへの共通対応付けは避け、その周回だけの修正を使ってください。
大型モデル・提出画像・個人データは配布に追加していません。

## v1.1.3の変更

KarenDrop v1.1.3

・水色の装備名を別の装備名と取り違える問題を修正しました。文字の比較用マスクと読取結果の再利用で水色の文字が落ちていたため、文字を保持するようにしました。
・発光で欠けた水色の長い品名と、白い品名の先頭を同じ文字行から補います。「リファインドボヘミアン帽子」「浄化された白い粉」等の修正例を確認しました。
・4K画面で見逃していた夢幻ラビの箱の金属枠を部分見本に追加しました。
・閉じた夢幻ラビの宝箱について、角度と小さい表示への参照を追加しました。床やキャラクター名は参照対象に含めません。
・水色の対応を品名の比較・分割に限定し、ゲージ等のUIを追加で拾わないようにしました。

v1.1.2以降は起動時に新版を確認し、「はい／いいえ」で更新を選べます。手動では「設定 → 更新を確認」を使用してください。履歴・学習・個人設定は引き継ぎます。

提供された新4K画像8枚は5/8枚から8/8枚へ箱検知が改善しました。閉じた箱16枚も、元の画素サイズで通常・4Kキャンバスに配置した両方の条件で検知しました。修正・参照作成に使った画像を含む開発検証であり、未知の画像や実機の連続動作の精度を保証する数字ではありません。
白い衣装や名前との重なり、一部の誤読、フィニージェムの断片、キャラクター名・インベントリ内の表示の混入は残ります。読み取った結果を確認してから周回を確定してください。
自動開始しない場合は「5秒後に報酬を読取」を使用してください。
大型認識モデルは追加していません。個人データ・提出画像は配布に含めません。
