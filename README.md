# KarenDrop v1.1.3

マビノギの画面に表示されたドロップ品名を読み取り、周回ごとの記録・確認・集計を行うWindowsツールです。

## ダウンロード

[公開リリース](https://github.com/GabbaAimGaming/mabinogi_drop_tracker/releases)のAssetsから `KarenDrop-v1.1.3-windows.zip` を取得し、すべて展開して `KarenDrop.exe` を起動してください。
Pythonの導入は不要です。Source code ZIPは開発者向けです。

操作は [README_EXE.txt](README_EXE.txt)、更新・復旧は [更新方法.txt](更新方法.txt)、制限と回避方法は [現在の問題点と対処方法.txt](現在の問題点と対処方法.txt) を参照してください。
OCR結果は確認してから確定してください。人形カバンなどが先に拾った品は画像から取得できません。

## 開発

構成・テスト・EXE作成は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。
記録、学習データ、提供者の画面サンプル、認証情報はリポジトリに含めません。
依存ソフト・モデル・画像等の権利情報は `licenses/` を確認してください。リポジトリのMITライセンスは第三者素材の権利を変更しません。

## v1.1.3の変更

KarenDrop v1.1.3

・水色の装備名を別の装備名と取り違える問題を修正しました。文字の比較用マスクと読取結果の再利用で水色の文字が落ちていたため、文字を保持するようにしました。
・発光で欠けた水色の長い品名と、白い品名の先頭を同じ文字行から補います。「リファインドボヘミアン帽子」「浄化された白い粉」等の修正例を確認しました。
・4K画面で見逃していた夢幻ラビの箱の金属枠を部分見本に追加しました。
・閉じた夢幻ラビの宝箱について、角度と小さい表示への参照を追加しました。床やキャラクター名は参照対象に含めません。
・水色の対応を品名の比較・分割に限定し、ゲージ等のUIを追加で拾わないようにしました。

v1.1.2以降は起動時に新版を確認し、「はい／いいえ」で更新を選べます。手動では「設定 → 更新を確認」を使用してください。履歴・学習・個人設定は引き継ぎます。

提供された新4K画像8枚は5/8枚から8/8枚へ箱検知が改善しました。閉じた箱16枚も、元の画素サイズで通常・4Kキャンバスに配置した両方の条件で検知しました。修正・参照作成に使った画像を含む開発検証であり、未知の画像や実機の連続動作の精度を保証する数字ではありません。
白い衣装や名前との重なり、一部の誤読、フィニージェムの断片、キャラクター名・インベントリ内の表示の混入は残ります。読み取った結果を確認してから周回を確定してください。
自動開始しない場合は「5秒後に報酬を読取」を使用してください。
大型認識モデルは追加していません。個人データ・提出画像は配布に含めません。
