# KarenDrop v1.1

マビノギの画面に表示されたドロップ品名を読み取り、周回ごとの記録・確認・集計を行うWindowsツールです。

## ダウンロード

[公開リリース](https://github.com/GabbaAimGaming/mabinogi_drop_tracker/releases)のAssetsから `KarenDrop-v1.1-windows.zip` を取得し、すべて展開して `KarenDrop.exe` を起動してください。
Pythonの導入は不要です。Source code ZIPは開発者向けです。

操作は [README_EXE.txt](README_EXE.txt)、更新・復旧は [更新方法.txt](更新方法.txt)、制限と回避方法は [現在の問題点と対処方法.txt](現在の問題点と対処方法.txt) を参照してください。
OCR結果は確認してから確定してください。人形カバンなどが先に拾った品は画像から取得できません。

## 開発

構成・テスト・EXE作成は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。

依存ソフト・モデル・画像等の権利情報は `licenses/` を確認してください。リポジトリのMITライセンスは第三者素材の権利を変更しません。

## v1.1の変更

KarenDrop v1.1

・複数フレームで同名の品名が少し動いた際、最後の照合で消える問題を修正。
・ペルシウスペレグリンサイズ／ペルシウスアークトゥルスオーブを辞書へ追加。
・提供サンプルで確認したオーブ先頭の「ベルシウス」を正式名へ補正。
・影ミッション5種（全面戦争、以夷制夷、スナイパー参戦、影の世界のチャンピオン、遭遇戦）とエリートを追加。
・影ミッション選択時はエリート／ネアル不使用を初期選択。プルダウンは最大6行でスクロール。
・影の報酬ES・装備・素材を補完し、辞書を414→440品へ拡充。
・青く発光した開封済み宝箱の角度・縮小見本を追加。
・画面共有スイッチと専用撮影処理を廃止。前面のゲーム画面を撮影する方式へ統一。

辞書登録だけで集計対象にはなりません。結果を確認してから確定してください。
宝箱検知は試験機能です。未収集の角度や小さい箱は見逃す場合があります。
影ミッションの実ゲームでの自動開始は未検証です。開始しない場合は5秒後の手動読取を使えます。
記録・学習・除外設定を保持します。過去に保存済みの読取結果は自動変更しません。
