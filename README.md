# KarenDrop v1.1.1

マビノギの画面に表示されたドロップ品名を読み取り、周回ごとの記録・確認・集計を行うWindowsツールです。

## ダウンロード

[公開リリース](https://github.com/GabbaAimGaming/mabinogi_drop_tracker/releases)のAssetsから `KarenDrop-v1.1.1-windows.zip` を取得し、すべて展開して `KarenDrop.exe` を起動してください。
Pythonの導入は不要です。Source code ZIPは開発者向けです。

操作は [README_EXE.txt](README_EXE.txt)、更新・復旧は [更新方法.txt](更新方法.txt)、制限と回避方法は [現在の問題点と対処方法.txt](現在の問題点と対処方法.txt) を参照してください。
OCR結果は確認してから確定してください。人形カバンなどが先に拾った品は画像から取得できません。

## 開発

構成・テスト・EXE作成は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。
記録、学習データ、提供者の画面サンプル、認証情報はリポジトリに含めません。
依存ソフト・モデル・画像等の権利情報は `licenses/` を確認してください。リポジトリのMITライセンスは第三者素材の権利を変更しません。

## v1.1.1の変更

KarenDrop v1.1.1

・複数フレームで同名の品名が少し動いた際、最後の照合で消える問題を修正。
・ペルシウスペレグリンサイズ／ペルシウスアークトゥルスオーブを辞書へ追加。
・提供サンプルで確認したオーブ先頭の「ベルシウス」を正式名へ補正。
・影ミッション5種（全面戦争、以夷制夷、スナイパー参戦、影の世界のチャンピオン、遭遇戦）とエリートを追加。
・影ミッション選択時はエリート／ネアル不使用を初期選択。プルダウンは最大6行でスクロール。
・影の報酬ES・装備・素材を補完し、辞書を414→440品へ拡充。
・青く発光した開封済み宝箱の角度・縮小見本を追加。
・画面共有スイッチと専用撮影処理を廃止。前面のゲーム画面を撮影する方式へ統一。

辞書登録だけで集計対象にはなりません。結果を確認してから確定してください。
宝箱検知は試験機能です。未収集の角度や小さい箱は見逃す場合があります。
影ミッションの実ゲームでの自動開始は未検証です。開始しない場合は5秒後の手動読取を使えます。
記録・学習・除外設定を保持します。過去に保存済みの読取結果は自動変更しません。

## v1.1.1の更新内容

KarenDrop v1.1.1

・夢幻ラビなどの宝箱検知を改善。従来の特徴点に、輪郭と箱の部分見本の補助照合を追加。
・箱を確認した後は既存の8秒の記憶を利用して負荷を抑制。ALTの3秒待機と中断時の解除は維持。
・赤いALT品名の読み取りに対応。HPバー、時計、百分率、明確な拾得メッセージの混入を抑制。
・4K/UI倍率判定と長い品名の途中分割を改善。複数フレーム間で動く品名が消える問題を修正。
・夢幻ラビのペルシウスペレグリンサイズ／ペルシウスアークトゥルスオーブを辞書へ追加し、提供画像で確認した誤読を補正。
・影ミッション5種（全面戦争、以夷制夷、スナイパー参戦、影の世界のチャンピオン、遭遇戦）とエリートを追加。プルダウンは最大6行でスクロール。
・影の報酬ES・装備・素材を補完し、辞書を440品へ拡充。
・フィニージェムは宝箱報酬ではないため初期状態では集計対象外。利用者が明示した設定を優先。
・画面共有スイッチを廃止し、前面のゲーム画面を撮影する方式に統一。

更新は「設定 → 更新を確認」から行えます。手動の場合はZIPをすべて展開してください。
記録・学習・利用者の除外設定を保持します。保存済みの過去の読取結果は自動変更しません。

宝箱検知は試験機能です。提供された4K静止画25枚は全て検知しましたが、開発・見本作成に使った画像を含み、未知の画像の精度を示す数字ではありません。
箱のない領域と、箱を消した比較画像の計125件では誤検知0。従来の青箱切り抜きは19/23枚でした。
未知の角度・強い重なりや発光・影ミッションの実機連続動作は未確認です。自動開始しない場合は手動読取を使用してください。
ALTは撮影完了音まで押し続け、読み取った内容と対象外の品を確認してから周回を確定してください。
