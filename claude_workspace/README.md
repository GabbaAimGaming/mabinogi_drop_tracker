# claude_workspace

Claudeが開発・調査・整理に使う場所。**リリースには含めない**（ルールは [RELEASE_RULES.md](RELEASE_RULES.md)）。

## 中身

| ファイル・フォルダー | 内容 |
|---|---|
| `CLAUDE.md` | v1.1のコードマップ。Claudeが編集する時の地図 |
| `RELEASE_RULES.md` | リリースに含めないためのルールと強制の仕組み |
| そのほか | `main`（v1.1、コミット `a79794c`）のスナップショット（軽量コピー） |

## 軽量コピーについて

- ソース、テスト、ドキュメント、小さい設定ファイルをコピーしている。
- 次は**コピーしていない**ので、このフォルダー単体ではアプリは起動できない。実体はリポジトリ直下を参照する。
  - `models/`、`assets/`、`references/`、`licenses/`
  - 画像（`.png`）、音声（`.wav`）、宝箱テンプレ（`.npz`）、OCRモデル（`.onnx`）、`.zip`
- このコピーは作成時点の`main`の写し。`main`が進んだら、必要な差分だけ取り込む。
- 写しの`README.md`は、このファイルに置き換えている（本物はリポジトリ直下の`README.md`）。

## 注意

- 本体のテストは `python tools/run_tests.py`（リポジトリ直下の`tests/`だけを対象にする）。このフォルダー内の`tests/`は参照用の写しで、通常は実行しない。
- ここで試した変更を本体に反映する時は、リポジトリ直下のファイルへ手作業で差分を移す。
